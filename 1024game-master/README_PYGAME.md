# 1024 Game - Pygame 图形版

一个功能完整的1024数字合并游戏，具有20个关卡、粒子特效、3D音效、多主题和数据持久化功能。

## 功能特性

### 核心游戏功能
- **20个关卡系统** - 从入门到终极大师，难度递增
- **4个难度等级** - 每5关难度明显提升
- **多种棋盘大小** - 3x3到6x6棋盘
- **智能合并算法** - 流畅的数字合并体验

### 视觉效果
- **粒子特效系统** - 合并、生成、胜利等特效
- **浮动文字** - 分数和连击显示
- **6种主题** - 经典、暗黑、海洋、森林、日落、霓虹
- **流畅动画** - 60FPS运行
- **自适应布局** - 支持窗口大小调整

### 音频系统
- **3D音效** - 根据位置调整音量和声相
- **程序化音效生成** - 无需外部音频文件
- **背景音乐** - 可选的背景音乐
- **音效类型** - 移动、合并、生成、胜利、失败等

### 用户界面
- **主菜单** - 游戏入口
- **关卡选择** - 显示关卡进度和评分
- **设置菜单** - 音量、主题、特效等设置
- **成就系统** - 16个成就待解锁
- **统计数据** - 详细的游戏统计
- **教程** - 新手引导

### 数据持久化
- **关卡进度** - 保存每个关卡的完成状态
- **最高分** - 记录最佳成绩
- **成就解锁** - 持久化成就状态
- **游戏会话** - 记录每次游戏数据
- **设置保存** - 保存用户偏好设置

## 安装

### 依赖要求
- Python 3.8+
- pygame 2.5.0+

### 安装步骤

1. 克隆或下载项目

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 运行游戏

### 启动游戏
```bash
python pygame_main.py
```

### 运行测试
```bash
python test_game.py
```

## 游戏控制

### 键盘控制
- **方向键** 或 **WASD** - 移动方块
- **ESC** - 暂停游戏
- **R** - 重新开始当前关卡

### 鼠标控制
- **点击** - 选择菜单选项
- **滚动** - 在成就列表中滚动

## 关卡系统

游戏包含20个关卡，分为4个难度等级：

### 第1-5关：入门级
- 3x3或4x4棋盘
- 目标：128-512
- 移动次数：70-100
- 适合新手学习游戏机制

### 第6-10关：中级
- 4x4棋盘
- 目标：1024-2048
- 移动次数：80-150
- 需要策略思考

### 第11-15关：高级
- 5x5棋盘
- 目标：2048-4096
- 移动次数：120-180
- 挑战性增加

### 第16-20关：大师级
- 6x6棋盘
- 目标：4096-8192
- 移动次数：150-250
- 终极挑战

## 成就系统

游戏包含16个成就：

### 基础成就
- 🎉 初次胜利 - 完成任意关卡
- ⭐ 初级玩家 - 完成第5关

### 分数成就
- 🥉 千分俱乐部 - 单局得分达到1000
- 🥈 五千分俱乐部 - 单局得分达到5000
- 🥇 万分俱乐部 - 单局得分达到10000

### 合并成就
- 🔢 1024大师 - 合并出1024
- 💎 2048大师 - 合并出2048
- 🌟 4096大师 - 合并出4096

### 关卡成就
- ⭐⭐ 中级玩家 - 完成第10关
- ⭐⭐⭐ 高级玩家 - 完成第15关
- 👑 终极大师 - 完成第20关

### 特殊成就
- 🔥 连击新手 - 达成5连击
- 💥 连击大师 - 达成10连击
- ✨ 完美游戏 - 不浪费任何移动完成关卡
- ⚡ 速度恶魔 - 30秒内完成关卡

## 主题系统

游戏提供6种视觉主题：

## 技术架构

### 文件结构
```
1024game-master/
├── pygame_main.py       # 主入口，游戏循环
├── pygame_game.py       # 游戏核心逻辑
├── pygame_ui.py        # UI组件
├── particles.py        # 粒子系统
├── audio.py           # 音效管理器
├── data_manager.py    # 数据持久化
├── themes.py         # 主题系统
├── test_game.py      # 测试套件
├── requirements.txt   # 依赖列表
└── data/            # 数据存储目录
    ├── settings.json
    ├── progress.json
    ├── achievements.json
    └── sessions.json
```

### 核心类

- **Game** - 游戏逻辑，关卡管理
- **ParticleSystem** - 粒子特效管理
- **AudioManager** - 3D音效系统
- **DataManager** - 数据持久化
- **ThemeManager** - 主题管理
- **GameApp** - 主应用程序

### 性能优化

- **60 FPS** - 流畅的游戏体验
- **多线程** - 音频和粒子系统独立运行
- **对象池** - 粒子复用，减少内存分配
- **增量渲染** - 只更新变化的部分
